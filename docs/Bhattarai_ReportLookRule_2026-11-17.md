# REPORT LOOK RULE

Set by Dilli, Nov 17 2026. Standing rule.

Every report, dashboard, board or status message built for Dilli or his clients
must look premium ("like a king") so people love it. Never basic or raw.

- Company-style layout
- Plain-English titles
- No raw log text
- Reference look: premium dark theme, near-black background, one accent color,
  big clean type

Applies to: emails, Telegram messages, dashboards, PDFs, client-facing boards.
